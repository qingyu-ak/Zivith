## 实测积压（下次分析后再改）

产品所有者 2026-09-16 晚测群聊后记下。**不要按此清单直接开工。**

### 1. 互聊太快 — 已做 2026-09-21

拍间留白改为上一句出现后再等 3.5 秒（`GROUP_BEAT_MS = 3500`）。用户说完后的第一句不拖。无速度旋钮。暂停交流 / 插话 / 停下来仍立刻打断等待。

### 2. 角色对白也要能回退；刻度改成侧面竖条 — 已做 2026-09-21

Chat / 扮演：每句对白一条侧面小横条；悬停拉长显示说话人与摘要；点选回退（该句还在、后面没发生过）。Agent 仍只给用户句打点。群聊实测：点角色条弹出「回退到这里 / 将拿掉 N 句」，取消后对话未改。

### 3. 用户扮演时，中途可以 AI 接管 — 已做 2026-09-21

已经能用顶栏「你扮演」换成书中角色。点「AI 接管」后，AI 替这个角色接着说（用户气泡）；「我来演」或打字接回。读者身份没有该按钮。群聊实测：扮楚子航后点接管，出现楚子航用户句并由路明非接话；点「我来演」或在输入框打字后按钮回到「AI 接管」。

### 4. 角色感不强 — 已做 2026-09-21

互聊时不像那个人。原因：档案和亲历压过口吻，括号动作互相抄，空拍把长亲历当讲义。本切片用角色卡「个性」做说话锁，不加心情旋钮。见 [task-s25-character-voice.md](task-s25-character-voice.md)。空卡不拦开聊；失败/取消/再进线程无新卡住状态。
